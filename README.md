## 概述

本包收录**风叶分离管理技术**的微风发电理论闭环与其技术规范标准初稿，作为 AI 技能（Skill）发布。核心思想：通过发电机转速实时监测 + 电磁离合器，动态控制参与做功的风轮层数，在保持单体风叶设计不变的前提下，把满功率风速从常规 12–18 m/s 降至 5 m/s 甚至更低，实现微风满功率发电与恒压恒功率输出。

## 核心公式

- 风力机功率：`P = ½·ρ·A·S³·C_p`（功率 ∝ 风速立方）
- 风叶分离满功率风速降低：`S₂ = S₁ / N^(1/3)`（N 为风轮层数）
  - 例：S₁ = 12 m/s，N = 3 → S₂ ≈ 8.32 m/s；8 组 → 约 6 m/s 起恒功率；24 组 → 5 m/s 微风满功率
- 扫风面积功率比：`总扫风面积 / 额定功率 > 20 m²/kW`（标准要求）

## 计算示例

```bash
python scripts/blade_separation.py --s1 12 --n 3 --unit-area 2.56 --total-area 23.04 --rated-kw 1
```

输出：S₁=12、N=3 → S₂=8.32 m/s；扫风面积功率比 23.04 m²/kW（>20，满足）。

## 试验结论（100 W 样机）

3.8 m/s 风速下，试验组（3 组风叶 + 电磁离合器 + 转速监控 + 1:1.7 增速齿轮）静止到 9.8 V 用时 **18 秒**，对比组 **10 分钟**（约 3:100）。
